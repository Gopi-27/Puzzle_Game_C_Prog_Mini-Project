# Mind_Grow_Game_Release
My First Mini Project Releasing

# Game Overview
Welcome Mind_Grow, a fun and strategic game for two players. 
The game has two versions: 
 1. Human vs Human 
 2. Computer vs Human

# Gameplay
Each player starts with three pins.
The objective is to arrange these pins on the board to form a straight line,
either vertically, diagonally, or horizontally.

# Gameplay Sequence
1. Players take turns placing one pin at a time.
2. Each player's turn consists of placing one pin, followed by the opponent's turn.
3. If a player fails to complete the game, they must move their pins alternatively until the game is won.

# Winning Conditions
The game is won when a player successfully forms a straight line with their three pins.
